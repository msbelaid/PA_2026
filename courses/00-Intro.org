** Complexity Review

| Data Structure    | Search    | Insert      | Delete      |
|-------------------+-----------+-------------+-------------|
| Array (unsorted)  | O(n)      | O(1)^{a}    | O(n)        |
| Sorted Array      | O(log n)  | O(n)        | O(n)        |
| Linked List       | O(n)      | O(1)^{b}    | O(1)^{c}    |
| Stack (push/pop)  | --        | O(1)        | O(1)        |
| Queue (enq/deq)   | --        | O(1)        | O(1)        |
| BST (average)     | O(log n)  | O(log n)    | O(log n)    |
| BST (worst)       | O(n)      | O(n)        | O(n)        |
| Heap              | O(n)      | O(log n)    | O(log n)^{d} |

**** Problem 2 
    :PROPERTIES:

    We have a linked list containing messages
    waiting to be processed.

    We frequently call the ~size()~ function.
**** Solution 2 (update the structure)
     :PROPERTIES:
     :BEAMER_act: <3->
     :BEAMER_env: exampleblock
     :END:
    #+BEGIN_SRC java
    class LinkedList {
        Node head;
        int size;
        int size() {
            return size;
        }
    }
    #+END_SRC
    Each insert ~size++~. Each delete ~size--~
 List size → $O(1)$

*** Solution
    :PROPERTIES:
    :BEAMER_col: 0.5
    :END:
**** Solution 1
     :PROPERTIES:
     :BEAMER_act: <2->
     :BEAMER_env: alertblock
     :END:
    #+BEGIN_SRC java
    int size() {
        Node current = head;
        int count = 0;
        while (current != null) {
            count++;
            current = current.next;
        }
        return count;
    }
    #+END_SRC

 List size → $O(n)$
